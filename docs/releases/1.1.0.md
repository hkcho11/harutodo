## 남은 배포 항목
- Vercel 로그인 후 운영 환경에 기존 운영 Supabase URL·공개 키·VAPID 및 서버 전용 `SUPABASE_SERVICE_ROLE_KEY`가 맞는지 확인한다. 키는 브라우저 코드나 문서에 기록하지 않는다.
- 앱 배포 및 실제 운영 비공개 경로·업데이트 안내·설치 안내 확인 후 태그를 만든다.
- 실기기 push 수신은 해당 기기의 설치·권한·구독 상태에 따라 별도 확인이 필요하다.
- 기존 의존성 감사에서 Next.js 15.5.18에 대한 critical 권고를 확인했다. 이번 기능이 새로 도입한 의존성은 아니며, 호환성 검증을 거친 보안 업데이트를 별도 후속으로 검토한다.

## Codex 자체 리뷰

### Critical
- 이번 구현 범위의 신규 문제 없음. 기존 프레임워크 보안 권고는 위 후속 항목에 기록했다.

### Major
- 앱 운영 반영은 Vercel 인증·서버 환경 확인이 남아 있어 아직 완료로 보고하지 않는다.

### Minor
- 실기기 push, 브라우저 메뉴의 버전별 차이, 초안 뒤로가기 잔여 history 검수.

### Keep
- 파트너와 분리한 의견 권한, 오래된 미답변 순서, 접수 후 알림 선택, 간단한 설치 설명, 기기별 확인한 버전만 숨기는 안내.

## 복구
- 앱은 위 기준 운영 커밋의 Vercel 배포로 복구한다.
- 새 의견 기능을 비활성화할 때는 새 예약 작업을 먼저 중단하고 사용자 의견·첨부는 보존한다. 자동으로 테이블·파일을 삭제하지 않는다.
- 기존 버전으로 되돌릴 때 출시한 태그를 다른 커밋으로 이동하지 않는다.
