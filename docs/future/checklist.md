# 핵심 플로우 수동 검수 체크리스트

작성일: 2026-06-02
기준: 375px 모바일 (iOS Safari / Android Chrome)

---

## 사전 조건

- 검수 기기: 375px 뷰포트 (Chrome DevTools 또는 실기기)
- 검수 계정: 연결된 커플 계정 A / B, 미연결 계정 C

## 1. 인증 플로우

| # | 시나리오 | 기대 동작 | 확인 |

| 1-4 | 회원가입 → 이메일 인증 안내 | "메일함을 확인해주세요" 화면 표시, "로그인으로 이동" CTA 노출 | |

## 3. 홈 화면 — 투두 플로우

| # | 시나리오 | 기대 동작 | 확인 |
|---|---|---|---|
| 3-1 | 앱 진입 → 오늘 날짜 선택 상태 | 오늘 날짜의 투두 리스트 즉시 표시 | |

| 3-4 | 투두 항목 탭 → 수정 시트 열림 | 기존 값 pre-fill, 저장 후 리스트 업데이트 | |

| 3-7 | 파트너가 투두 추가/수정/삭제 | 내 화면에 실시간 반영 (Realtime) | |
| 3-8 | 내 할 일 / 파트너 할 일 / 함께 / 커스텀 그룹 구분 표시 | 5초 이내 각 섹션 구분 확인 가능 | |

| 4-8 | 파트너 일정 추가 | 내 캘린더에 실시간 반영 | |
| 4-9 | 이전/다음 달 이동 | 해당 월 일정 정상 로드 | |
