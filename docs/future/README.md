# Future Work

작성일: 2026-06-02

이 디렉토리는 하루투두의 이후 추가 개발 기능과 고도화 작업을 제품 관점에서 정리하는 공간이다.
코드 구현 지시가 아니라, Codex가 구현 전에 MVP 여부와 우선순위를 판단할 때 참고할 제품 백로그로 사용한다.

## 사용 원칙

- 하루투두의 핵심 가치는 커플 공유 투두와 캘린더를 빠르게 확인하고 함께 관리하는 경험이다.
- 새 기능은 "오늘 할 일 파악", "파트너 구분", "반복 사용 부담 감소", "모바일 PWA 품질" 중 하나 이상에 직접 기여해야 한다.
- 미승인 기능은 먼저 구현하지 않고 백로그에 보류한다.
- 스키마 변경, 새 라이브러리 추가, 큰 구조 변경이 필요한 항목은 사용자 승인 후 별도 태스크로 다룬다.
- Codex 자체 리뷰와 대표 피드백 반영은 `Critical / Major / Minor / Keep` 형식을 유지한다.

## 우선순위 기준

| 등급 | 의미 |
|---|---|
| P0 | 즉각적인 사용자 경험 손상 또는 보안/데이터 무결성 문제 — 다음 배포 전 반드시 해결 |
| P1 | 핵심 지표(리텐션, 완료율, 커플 연결율)에 직접 기여하는 개선 — 우선 처리 |
| P2 | 제품 방향에는 맞지만 사용성 검증 이후 판단해도 되는 확장 작업 |
| Hold | 현재 단계에서는 보류하거나 명확한 사용자 니즈 확인 전까지 구현하지 않을 작업 |

## 항목 작성 형식

각 백로그 항목은 다음 정보를 포함한다.

- 목적: 사용자가 얻는 가치
- 범위: 이번 태스크에서 다룰 최소 구현 범위
- 검수 기준: 모바일 375px, 접근성, 데이터 권한, 빈/로딩/에러 상태 등 확인 포인트
- 의존성: 스키마, RLS, 서비스 계층, PWA 설정, 디자인 시스템 등 선행 조건
