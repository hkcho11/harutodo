# 하루투두 포트폴리오 제작 문서

이 폴더는 하루투두를 과장 없이 설명하고, 면접에서 구현과 의사결정을
직접 설명할 수 있도록 만든 포트폴리오 원본 자료다.

## 문서 구성

- `01-project-audit.md`: 실제 코드와 Git 이력을 기준으로 정리한 프로젝트 감사
- `02-portfolio-draft.md`: 포트폴리오 상세 페이지에 사용할 원고 초안
- `03-case-studies.md`: 권한, Realtime, 알림을 중심으로 한 핵심 사례 연구
- `04-interview-guide.md`: 기술 해설, 예상 질문, 발표 스크립트
- `05-diagrams.md`: 사용자 흐름, 시스템, DB, Realtime, 알림 다이어그램
- `06-production-capture-guide.md`: 운영 화면 촬영·익명화·삽입 기준
- `07-demo-crud-scenario.md`: 개발환경 데모 데이터와 실제 CRUD 캡처 시나리오
- `08-job-positioning.md`: Java·React 지원 직무별 강조점과 답변
- `09-user-feedback.md`: 실사용 파트너 피드백, 제품 백로그, 문서 보안 검토
- `site/`: 독립적으로 확인할 수 있는 포트폴리오 웹 초안

## 작성 원칙

1. 저장소에서 확인되지 않는 사용자 수, 성과 수치, 개발 기간은 추측하지 않는다.
2. “직접 작성한 코드의 양”이 아니라 문제 정의, 의사결정, 검증 책임을 설명한다.
3. AI 활용 사실은 숨기지 않고 개발 프로세스와 품질 통제 방식으로 설명한다.
4. 현재 구현의 한계와 기술 부채도 함께 공개한다.
5. 면접 전에 이 문서의 모든 기술 용어를 자신의 말로 설명할 수 있어야 한다.

## 다음 제작 단계

1. 대표 확인이 필요한 사실을 확정한다.
2. 실제 모바일 화면과 사용 흐름을 촬영한다.
3. 시스템 구성도와 데이터 모델을 시각화한다.
4. 원고를 포트폴리오 웹 페이지로 구현한다.
5. 공개 저장소의 비밀정보와 불필요한 파일을 별도로 점검한다.
