→
대체 설계

Scriptable이 하루투두의 월간 일정·오늘 할 일 API를 직접 조회하도록 구성했습니다.

→
원본과 권한

데이터를 복제하지 않고 JWT, 커플 멤버십과 RLS를 거쳐 같은 원본을 읽게 했습니다.
